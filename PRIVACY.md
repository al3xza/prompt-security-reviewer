# Privacy policy

Prompt Security Reviewer is a set of instructions and reference files for Claude. It is not a service and has no backend.

## What it collects

Nothing. The plugin runs no code, opens no network connections, and has no servers, accounts, analytics or telemetry of its own.

## What it sends

Nothing beyond your normal use of Claude. When you use the skill, the prompt you ask Claude to review is handled by Claude like any other message in your conversation. That processing is covered by the privacy policy of whoever provides your Claude access (for example Anthropic, or your employer's deployment). This plugin adds no recipients and no extra data flows.

## Sensitive values in a reviewed prompt

If the prompt you paste contains secrets or personal data, it is processed as part of your conversation like any other text. The skill is instructed to redact secrets and personal data in its output, but you should avoid pasting real credentials; use placeholders instead.
